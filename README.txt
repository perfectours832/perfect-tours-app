Perfect Tours — אפליקציית חופשות

זהו שדרוג של הפרויקט הקיים. אין שינוי בסכמת Supabase ואין המרה אוטומטית של נתונים.
אין לפרסם לפני מעבר על docs/RELEASE-CHECKLIST.md ואישור בעל הפרויקט.

פתיחה מקומית
-------------
בתיקיית הפרויקט הריצו:
  npm start
פתחו http://127.0.0.1:4173

האפליקציה הרגילה משתמשת בחיבור Supabase הקיים. שמירה לאחר התחברות
עלולה לעדכן נתונים אמיתיים. הבדיקות האוטומטיות חוסמות גישה חיצונית
בדפדפן ומשתמשות בנתוני TEST ONLY בלבד.

בדיקות
------
נדרשים Node.js 20 ומעלה ו-Python 3 להפעלה מקומית.
  npm ci
  npx playwright install chromium
  npm test

אם Chromium כבר מותקן ב-/usr/bin/chromium, הבדיקות משתמשות בו.
ניתן לבחור נתיב אחר דרך PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH.
  npm run test:model
  npm run test:browser

צילומי המסך שנוצרים בבדיקות נמצאים ב-artifacts/ וכוללים נתונים סינתטיים בלבד.
תיקייה זו אינה נכללת ב-Git. אין צורך בשלב build לאפליקציה הסטטית.

מבנה
----
index.html — נקודת כניסה יחידה; ?trip=PUBLIC_ID מציג את ממשק הלקוח.
app.js — התחברות, ניתוב ופעולות Supabase הקיימות.
itinerary-model.js — חוזה הנתונים ושימור מסלולים ישנים.
client-view.js / client.css — תצוגת הלקוח.
trip-editor.js / editor.css — עורך ימים ופעילויות.
admin.css — סגנונות הממשק הניהולי.
legacy-entry.js — הפניית admin.html, client.html ו-index-new.html לדף הפעיל.
password.html — מסך הסיסמה הקיים, ללא שינוי.
styles.css, sw.js וקובצי ZIP — שרידים היסטוריים שאינם נטענים בגרסה החדשה.

המערכת שומרת מסלול מובנה כמערך באותה עמודת itinerary. מסלול שלא נערך
נשלח ללא שינוי. מסלול ישן מוצג במלואו ומומר רק דרך תצוגה מקדימה והחלה
מפורשת בעורך. לפני שמירת המרה ניתן להוריד את המקור ולשחזרו בעורך.

אימות משתמשים נשאר ב-Supabase Auth. בקוד מופיע מפתח publishable ציבורי בלבד.
אין להוסיף service_role, סיסמאות או מפתחות סודיים לקובצי האתר.
הרשאות השרת, פרטיות מסמכים וסינון טיוטות עדיין דורשים אימות בסביבת בדיקות.
