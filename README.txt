PERFECT TOURS - מערכת מחוברת ל-Supabase

כתובת הפרויקט כבר הוגדרה:
https://pcwosixpckdiodixmvhq.supabase.co

לפני העלאת האתר:
1. היכנס ל-Supabase > SQL Editor.
2. פתח את הקובץ supabase-setup.sql, העתק את כולו ולחץ Run.
3. היכנס ל-Authentication > Users.
4. לחץ Add user וצור משתמש עם האימייל והסיסמה שלך.
5. העלה את כל הקבצים שבתיקייה הזאת ל-Netlify.
6. פתח /admin.html והתחבר.
7. צור חופשה ושלח ללקוח את הקישור שנוצר.

חשוב:
- אין לשלוח לאף אחד את סיסמת המנהל.
- המפתח שב-config.js הוא Publishable Key ציבורי, לא Secret Key.
- אל תכניס אף פעם service_role או sb_secret לקבצי האתר.
